Struct RectangleF

Namespace
HelixToolkit.Maths
Assembly
HelixToolkit.Maths.dll

Define a RectangleF. This structure is slightly different from System.Drawing.RectangleF as it is internally storing Left,Top,Right,Bottom instead of Left,Top,Width,Height.
